# Nyaruhodo

*[Read in English](README.md)*

Petits outils légers pour Windows et Linux par Nyaldee, et un bot Discord. Chaque outil tient en un seul exécutable : pas d'installateur, rien à configurer à part vos propres préférences. Les téléchargements sont dans les [releases](https://github.com/Nyaldee/nyaruhodo/releases) ; plus d'informations sur [nyaruhodo.com](https://www.nyaruhodo.com/).

## Applications

| Application | Plateformes | Documentation |
|---|---|---|
| **MAGI Launcher** — lanceur d'applications entièrement au clavier : recherche approximative, calculatrice, sélecteur de fenêtres, minuteur, notes, historique du presse-papiers, éjection USB et plus de 100 thèmes de couleurs | Windows, Linux | [English](MAGI%20Launcher/README.md) · [Français](MAGI%20Launcher/README.fr.md) · [日本語](MAGI%20Launcher/README.jp.md) · [中文](MAGI%20Launcher/README.zh-CN.md) |
| **CASPER Shot** — captures d'un écran ou d'une zone par raccourci global, copiées dans le presse-papiers et enregistrées en WebP | Windows | [English](CASPER%20Shot/README.md) · [Français](CASPER%20Shot/README.fr.md) · [日本語](CASPER%20Shot/README.jp.md) · [中文](CASPER%20Shot/README.zh-CN.md) |
| **Solar RIP** — patcheur dans les deux sens pour le format `.rip`, sans limite de taille : le même patch applique et restaure | Windows, Linux | [English](Solar%20RIP/README.md) · [Français](Solar%20RIP/README.fr.md) · [日本語](Solar%20RIP/README.jp.md) · [中文](Solar%20RIP/README.zh-CN.md) |
| **Silent CMD** — lance une commande ou un script sans fenêtre de console, depuis un raccourci ou le Planificateur de tâches | Windows | [English](Silent%20CMD/README.md) · [Français](Silent%20CMD/README.fr.md) · [日本語](Silent%20CMD/README.jp.md) · [中文](Silent%20CMD/README.zh-CN.md) |
| **Truncate** — donne à un fichier exactement la taille voulue : le créer, l'agrandir, le réduire ou décaler son contenu | Windows, Linux | [English](Truncate/README.md) · [Français](Truncate/README.fr.md) · [日本語](Truncate/README.jp.md) · [中文](Truncate/README.zh-CN.md) |

## Téléchargement

Toutes les applications sont dans la [dernière release](https://github.com/Nyaldee/nyaruhodo/releases/latest), en `.zip` pour Windows et en `.tar.gz` pour Linux. Extrayez l'archive et lancez l'exécutable qu'elle contient ; les notes de version expliquent comment mettre à jour.
