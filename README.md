# Nyaruhodo

Small, lightweight tools for Windows and Linux by Nyaldee. Each one is a single executable: no installer, nothing to set up beyond your own preferences. Downloads are in the [releases](https://github.com/Nyaldee/nyaruhodo/releases); more on [nyaruhodo.com](https://www.nyaruhodo.com/).

## Applications

| Application | Platforms | Documentation |
|---|---|---|
| **MAGI Launcher** — keyboard-only application launcher: fuzzy search, calculator, window switcher, timer, sticky notes, clipboard history, USB eject and over 100 color themes | Windows, Linux | [English](MAGI%20Launcher/README.md) · [Français](MAGI%20Launcher/README.fr.md) · [日本語](MAGI%20Launcher/README.jp.md) · [中文](MAGI%20Launcher/README.zh-CN.md) |
| **CASPER Shot** — screenshots of a screen or a region by global hotkey, copied to the clipboard and saved as WebP | Windows | [English](CASPER%20Shot/README.md) · [Français](CASPER%20Shot/README.fr.md) · [日本語](CASPER%20Shot/README.jp.md) · [中文](CASPER%20Shot/README.zh-CN.md) |
| **Solar RIP** — two-way patcher for the `.rip` format, with no size limit: the same patch applies and restores | Windows, Linux | [English](Solar%20RIP/README.md) · [Français](Solar%20RIP/README.fr.md) · [日本語](Solar%20RIP/README.jp.md) · [中文](Solar%20RIP/README.zh-CN.md) |
| **Silent CMD** — runs a command or script with no console window, from a shortcut or the Task Scheduler | Windows | [English](Silent%20CMD/README.md) · [Français](Silent%20CMD/README.fr.md) · [日本語](Silent%20CMD/README.jp.md) · [中文](Silent%20CMD/README.zh-CN.md) |
| **Truncate** — gives a file the exact size you want: create it, extend it, shrink it or shift its content | Windows | [English](Truncate/README.md) · [Français](Truncate/README.fr.md) · [日本語](Truncate/README.jp.md) · [中文](Truncate/README.zh-CN.md) |

## Download

Every application is in the [latest release](https://github.com/Nyaldee/nyaruhodo/releases/latest), as a `.zip` for Windows and a `.tar.gz` for Linux. Extract it and run the executable inside; the release notes explain how to update.

## Made with

MAGI Launcher and Solar RIP use [Slint](https://slint.dev) for their interface.
