# Nyaruhodo

*[Lire en français](README.fr.md)*

Small, lightweight tools for Windows and Linux by Nyaldee, and a Discord bot. Each tool is a single executable: no installer, nothing to set up beyond your own preferences. Downloads are in the [releases](https://github.com/Nyaldee/nyaruhodo/releases); more on [nyaruhodo.com](https://www.nyaruhodo.com/).

## Applications

| Application | Platforms | Documentation |

## Download

Every application is in the [latest release](https://github.com/Nyaldee/nyaruhodo/releases/latest), as a `.zip` for Windows and a `.tar.gz` for Linux. Extract it and run the executable inside; the release notes explain how to update.
